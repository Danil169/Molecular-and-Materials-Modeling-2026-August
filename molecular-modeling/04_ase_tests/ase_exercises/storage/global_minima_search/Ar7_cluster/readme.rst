========================
Ar7 global minima search
========================

In the Atomic Simulation Environment (ASE), the most common way to perform a global minima search is using the Basin Hopping algorithm. It works by combining random structural perturbations with local geometry optimizations.
A classic benchmark is finding the ground state of a Lennard-Jones (LJ) cluster. Below is a complete Python example using a cluster of 7 Argon atoms.
