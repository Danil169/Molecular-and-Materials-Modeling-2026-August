==================
Molecular Modeling
==================

Working files for the Hybrid School on Molecular and Materials Modeling.

This directory holds Part I calculation materials. The current submission-ready
reports are in the repository root: ``../Report_Materials_Modeling_EN.docx``
and ``../Report_Materials_Modeling_RU.docx``.

Each Git-tracked subdirectory has a ``readme.rst`` with its description and
associated exercise or challenge.
