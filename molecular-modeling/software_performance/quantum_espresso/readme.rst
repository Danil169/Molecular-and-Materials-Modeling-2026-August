quantum espresso
----------------

This directory contains Quantum ESPRESSO MPI-scaling benchmark inputs and
measured timings used in Exercise I.2 and Fig. 1 of the final report.

Contents
--------

Files are retained as part of the reproducible course-work record. Inputs and
scripts define the calculation; log, trajectory, and data files record its
results. Consult the nearest parent ``readme.rst`` for the exercise-level
workflow and interpretation.
